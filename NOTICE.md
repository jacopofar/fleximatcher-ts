## Upstream

The data comes from English Wiktionary, extracted into JSONL by
[wiktextract](https://github.com/tatuylonen/wiktextract), a project by Tatu
Ylonen and contributors (MIT-licensed).  The ready-made dump is published by
[kaikki.org](https://kaikki.org/dictionary/).

## Obtaining the raw input

The raw dump is not committed to this repository.  What it is, where to
download it, and which fields this project reads from it are documented in
[`tools/wiktextract/README.md`](./tools/wiktextract/README.md).

## Provenance of generated artifacts

A generated lexicon starts with a header recording the lexicon format version,
the language and the `generatedAt` build timestamp.  It does **not** record
which dump it was built from, so keep the dump date alongside the artifact (a
file name such as `raw-wiktextract-2026-10-01.jsonl.gz` is enough) if you need
to trace a lexicon back to a source snapshot.

If you redistribute a generated lexicon, keep this attribution and the license
notice that ships with the source dump.
